# Politique de confidentialité

*Version publiée en V1 · Dernière mise à jour : 16 septembre 2026*

CnH se lit **sans compte**. Il n'y a **ni publicité, ni mesure d'audience, ni cookie, ni traceur**.

## 1. Qui est responsable ?

L'éditeur de CnH, projet personnel et sans but lucratif (voir les [Mentions légales](mentions-legales.md)). Contact : **[vezybrehauxhugo@gmail.com](mailto:vezybrehauxhugo@gmail.com)**.

## 2. Quelles données sont collectées ?

**Aucune par l'éditeur.** Le site ne propose ni compte, ni formulaire, ni commentaire. Il n'utilise aucun cookie, ne stocke rien sur ton appareil et ne charge aucune ressource venant d'un autre site (police, statistiques, vidéo…).

## 3. L'hébergeur

Le site est hébergé par GitHub (service GitHub Pages). GitHub enregistre l'adresse IP des visiteurs à des fins de sécurité, que le visiteur ait un compte GitHub ou non. GitHub, Inc. est une société établie aux États-Unis ; ce traitement est décrit dans sa [déclaration de confidentialité](https://docs.github.com/privacy).

## 4. Liens vers d'autres sites

Les sources citées sous chaque carte renvoient vers des sites extérieurs (UNESCO, Insee…). Une fois sur ces sites, ce sont leurs propres règles de confidentialité qui s'appliquent.

## 5. Tes droits

Pour toute question sur tes données, écris à l'adresse de contact ci-dessus. Pour les données de connexion enregistrées par l'hébergeur, adresse-toi à GitHub. Tu peux aussi saisir la **CNIL** (www.cnil.fr).

## 6. Et après ?

Si CnH ouvre des comptes ou un forum, cette politique sera complétée **avant** toute collecte de données.
